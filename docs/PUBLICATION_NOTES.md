# 公开版本说明

以 2026 年 9 月投稿使用的 MarketGenesis v2.1 复现包为基底，保留数值实验、逐路径数据、固定配置与参考图。公开版本整理日期：2026-10-08。

本次整理改善阅读入口、修复独立校验器的包内路径、修正不同字体下 ABC 图的文字重叠，并增加自动化检查。未为了改善指标而修改模拟器、筛选规则或已保存数据。

## 展示材料

- 三份 PDF 为原投稿材料的公开副本，移除了私人电话、邮箱及文件元数据；研究观点与参考文献保留。
- 演示视频是原文件的逐字节副本，没有修改画面、音频、时长或编码。
- 网页演示属于预计算参考数据回放，完整计算通过 Python 入口运行。
- 历史材料中的“最大回撤”以 README 定义为准：相对冲击前锚点的最大损失，不是滚动峰谷回撤。
- 历史申请书中的预算与计划不代表款项已到账、方向已实现或成果经过外部同行评审。

## 可追溯性

参考数据及图表的 SHA256 清单在两个 reference 目录的 data/artifact_hashes.sha256 中。展示材料另有 assets/SHA256SUMS。

同一配置与软件版本应重现相同数值；字体或平台造成的绘图差异不等于数值变化。CI 状态以实际日志为准，不把新增工作流文件当作已通过 GitHub Actions 的证据。
