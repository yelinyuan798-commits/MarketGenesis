# 对外分享说明

## 推荐入口

最好把整个文件夹放入一个公开或私有只读的 GitHub/Gitee 仓库。评审打开后先看到 `README.md`，无需下载即可理解实验；需要复现时再下载仓库。

如果暂时不用代码平台，也可以上传压缩包 `MarketGenesis_代码数据与一键复现.zip` 到网盘，并设置为：

- 只读；
- 不需要申请权限；
- 链接在无痕浏览器中可以打开；
- 有效期覆盖整个评审周期。

邮件正文只放链接，不直接附 `.py`、`.html` 或大型 ZIP，以免触发企业邮箱过滤。

## 上传前不要包含

- `.venv/`：本机安装环境，体积大且不可移植；
- `reproduced/`、`robustness_reproduced/`：评审应当能够自己生成；参考结果已经放在 `reference/` 与 `reference_robustness/`；
- `.DS_Store`、缓存和个人路径；
- API 密钥、账号、真实交易凭证或私人数据。
