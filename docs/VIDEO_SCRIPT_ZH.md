# MarketGenesis 约 90 秒真人演示（好说版·终局版）

这一版按实际录制语速压缩到约 275 个中英文字符。正常语速加点击停顿，目标时长约 85—95 秒。

## 录制前只做这五件事

1. 先运行一次 `RUN_FIXED_SEED_MAC.command`（Windows 使用 `RUN_FIXED_SEED_WINDOWS.bat`），让依赖和缓存准备完成。
2. 打开演示页，点击“重置”，再把网页放大。不要从访达或桌面开始录。
3. 打开“专注模式”。录制区域只框住网页内容，尽量不录地址栏、菜单栏和 Dock。
4. 每说完一句再点击；不要边念数字边找按钮。
5. 结尾停在 PASS 成果页，直接点击菜单栏的“停止录制”按钮，不要再打开录屏选区框。

## 逐秒操作与口播

只念引用框里的文字。“停半秒”和操作说明不要念出来。

演示页是预计算参考结果的交互回放；点击冲击或探针按钮不会重新运行模拟。55—70 秒的 Python 复现步骤才是重新计算。

### 0—16 秒｜开场

操作：画面已经停在演示首页，鼠标不动。

> 两个市场历史完全相同，却在同一冲击后走向不同未来。（停半秒）那价格，真的就是市场吗？大家好，我是 Evan 云期。

### 16—25 秒｜指出冲击前重合

操作：鼠标指向虚线左侧的重合轨迹。

> 这是两个内部结构不同的人工市场。冲击前，观测重合，差异为零。

### 25—42 秒｜施加同一冲击

操作：先说第一句，再点击红色按钮。等红蓝两条线分开后，指向右侧数字。

> 这里回放同一个冲击后的结果。红色市场触发强平。最大回撤相差四点二五个百分点。（停半秒）峰值价差相差十六点三一个基点。

### 42—55 秒｜主动辨识

操作：点击深蓝色按钮，指向 `700→70`。

> 只看历史，我们不知道自己身处哪种市场。所以系统保留候选，主动试探，把七百个缩到七十个。

### 55—70 秒｜一键复现

操作：运行 `RUN_FIXED_SEED_MAC.command` 或 `RUN_FIXED_SEED_WINDOWS.bat`，等结果页自动打开。

> 我现在固定随机种子重跑。页面出现 PASS，说明数据、图表和检查已经重新生成。

### 70—95 秒｜成果页与终局

操作：结果页全屏，让三张图和 PASS 留在画面中，不再移动鼠标。

> 这只是第一步：同样的价格背后，可以藏着不同的世界。MarketGenesis 的终点，是让机器看见价格背后的机制，辨认自己身处的世界，再搜索怎样把它推向目标。（停半秒）传统量化追赶价格，我们要开始设计市场的未来。

## 最容易读错的地方

- `Evan 云期`：在 Evan 后面稍停，说成“Evan，云期”。
- `4.25pp`：只说“四点二五个百分点”。
- `16.31bps`：只说“十六点三一个基点”。
- 不再口播 `0.330→0.278` 和 `1.896→0.934`，让它们留在成果页上，避免数字口误。

## 录制时不要说

- 不要说已经预测真实市场；
- 不要说已经证明能盈利；
- 不要把 `700→70` 说成“准确率提升了 90%”。
