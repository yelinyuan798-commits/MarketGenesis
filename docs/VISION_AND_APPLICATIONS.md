# MarketGenesis：让决策看见不止一个未来

> 不只问“下一步会发生什么”，还要问“为什么会这样”“怎样区分不同解释”，以及“如果我错了，哪一个行动仍然可靠”。

本文描述应用设想与研究路线。它不增加已完成成果的范围，也不表示下面的产品已经存在。

## 不是再造一个预测分数，而是建立一座可能世界实验室

市场看起来风平浪静，并不代表内部没有脆弱性。两套系统也许留下了相似的历史，却因杠杆、库存或约束不同，对未来同一件事产生完全不同的反应。

我们希望形成一种工作方式：让多个解释同时存在，让同一个行动在它们之中接受检验，再根据新证据排除不相容的解释。模型不必假装知道唯一的真相，但需要说清楚：不确定性在哪里，它会改变什么，以及怎样花更小的代价去认识它。

当前原型实现了其中一小段：在同一人工市场方程中生成有限候选参数，使用预设探针比较响应，并在独立随机创新和未参与筛选的剂量上检查效果。还没有从真实观测自动恢复完整机制、最优探针搜索或行动规划。

## 方向一：把风险从一个数字，展开成一条发生路径

**设想中的使用者：**风险研究者、复杂系统研究者与压力测试团队。

同样一段平静行情，可能对应杠杆健康的结构，也可能对应保证金缓冲极薄、参与者高度拥挤的结构。传统风险指标有其价值；这里想补充的问题是：哪些候选机制会在某种冲击后产生不同反应？

设想中的输出不是“明天跌 3%”，而是：

- 哪几类机制仍与现有数据相容；
- 哪些条件会引发强制平仓、流动性撤回与反馈放大；
- 哪些压力响应对模型假设最敏感；
- 哪项额外观测最可能改变判断。

**要证明用途，不能只展示漂亮分叉图。** 需要真实数据校准、跨模型验证、时间外检验，并与现有压力测试和统计基线比较。若不能改善风险识别或不确定性校准，就不能宣称它是更好的风险工具。

## 方向二：让规则先在计算机里经历一次后果

**设想中的使用者：**研究市场规则、组织协调与机制设计的团队。

提高保证金可能限制杠杆，也可能在某些条件下增加集中去杠杆的压力。改变交易频率可能抑制某种反馈，也可能影响价格发现。这些方向都不应仅凭直觉选边；具体影响需要建模与检验。

目标是建立一个规则沙盒：对同一个规则改动，在不同候选机制中运行对照，展示收益、代价、尾部风险与分歧。好的方案不是只在一个被精心选中的模拟器中取胜，而是在多个合理解释下仍能通过检验。

**当前未实现规则优化。** 后续必须增加可变化的规则模块、主体对规则的适应、明确的目标与约束、跨模型对照和部署前审查。模拟器里的表现不能代替真实政策或金融决策所需的证据。

## 方向三：让机器人分清“发生了什么”与“为什么发生”

**设想中的使用者：**多机器人协作与智能体系统研究者。

同样是几台机器人行动迟缓，原因可能是电量不足、通信延迟、通道被阻塞，或任务相互冲突。直接复用上一回有效的动作，可能刚好针对了错误原因。

若能保留多个候选解释，系统可以先在安全约束内做一次小测试，例如请求一次状态回传，或安排一个低成本、不妨碍其他机器的任务，再依据响应调整判断。更远一步，是比较不同原因下的行动后果，寻找即便判断尚未确定也不会造成明显损害的方案。

**这不是将金融代码直接装进机器人“大脑”。** 可迁移的是“多解释、主动取证、稳健行动”的研究结构。需要重新定义状态与动作、搭建独立任务环境、设计安全探针，并进行仿真到实体的验证。当前没有机器人性能数据。

## 如果做成，它最终可能是什么样的工具？

一个面向研究者的“机制决策工作台”，让使用者完成四件事：

1. **提出解释。** 输入可观测数据、已知规则与待检验机制，得到一组仍与证据相容的候选，而不是一个未经验证的确定答案。
2. **比较未来。** 为同一行动生成条件化响应，观察哪个方案依赖哪个解释，以及哪些分歧会影响决策。
3. **选择下一次取证。** 把辨识收益、实验成本与安全约束一起考虑，建议最值得补充的证据。
4. **在不确定中行动。** 当真机制无法唯一确定时，寻找在多个合理世界下都能承受的方案，同时报告候选库可能漏掉的机制。

这些界面与功能是愿景，不是已开发产品。候选也不能凭空覆盖所有可能世界；候选生成范围、失配检测和外部验证始终是关键限制。

## 如何知道我们在前进，而不是把故事讲得更大？

| 问题 | 需要的证据 |
| --- | --- |
| 候选是不是只会猜自己熟悉的世界？ | 把真机制放到候选家族之外，检验失配识别与不确定性覆盖 |
| 主动取证真的比等数据或随机探测更好？ | 与被动观测、随机探针、固定探针在相同成本下比较 |
| 多个世界是不是只增加了计算负担？ | 与单模型、强统计基线比较留出预测、决策损失与计算开销 |
| 仿真收益能不能带到现实？ | 独立数据、独立任务环境与真正的样本外检验 |

如果这些比较失败，结论就应缩小，而不是靠新的术语掩盖失败。

## 市场是起点，机制驱动的决策是远方

从 Market Intelligence，到 Market Ontology，再到 Market Engineering，可以理解为三个逐步加深的问题：能否解释正在发生的事，能否识别产生它的结构，能否检验改变规则后的后果。

**MarketGenesis 的想象力不在于宣称我们已经掌握世界，而在于让智能系统学会认真对待：世界可能不是它以为的那个样子。**
